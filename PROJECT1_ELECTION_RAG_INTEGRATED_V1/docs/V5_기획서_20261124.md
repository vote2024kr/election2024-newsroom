# 제22대 국회의원선거 · 데이터 저널리즘 웹 상황실 기획서

## 1. 프로젝트 정의
- 프로젝트: **2024년 22대 국회의원 선거 시간대별 투·개표 현황**
- 용도: 데이터 저널리즘 교육 프로젝트 1, 10~20분 분량 선거 분석 영상 시각자료 제작
- 이용자: 선거 결과를 전국 단위로 빠르게 파악하거나 개별 지역구 결과를 조사하려는 학습자·시민
- 핵심 과제: 동일한 지도를 중복 제공하던 전국 확정 개표와 지역별 탐색 메뉴의 역할을 분리한다

## 2. 정보 구조
1. **2024 투·개표 상황** — 투표율 시간별 증가, 13시 사전투표 반영 안내, 지역구·비례대표 개표 진행 및 10:25 최종 결과 공개
2. **전국 확정 개표** — 지역별 당선 정당 색상 지도 + 정당별 지역구·비례대표 도넛 + 300석 반원 + 정당별 의석표
3. **지역·선거구 탐색** — 확대 전국 지도 → 시·도 지도 → 시·군·구 목록 → 지역구 → 최종 후보별 득표와 투표율
4. **비례대표 개표·투표율 분석·개표 분석** — 기존 메뉴와 원자료 보존
5. **기사·RAG·CG·CSV·학습·미디어** — 기존 기능 유지

## 3. 화면 연출
- 배경: 어두운 네이비, 강조: 청록, 정당 지도: 기존 정당색
- 최종 전국 결과에서는 세부 선택을 제거해 방송 CG처럼 한눈에 보이는 개요 제공
- 지역 탐색에서는 **전국 지도 2배 이상 확대**를 목표로 하고 지도 2개와 후보 상세를 상단에 고정된 관계로 배치
- 시·도와 시·군·지역구 목록은 하단의 별도 패널로 내림. 목록의 화면 밖 부분은 스크롤
- 시·도 선택과 지역구 선택은 URL 매개변수로 표현해 직접 링크 공유가 가능
- 원시 투표수·선거인수와 계산된 퍼센트를 동시에 제시하여 사용자 검증 가능

## 4. 영상 활용
- 도입: 전국 시간별 투표율 선 그래프 → 13시 주석
- 본론 1: 과거 개표 진행 화면 → 10:25 전국 확정 지도·300석 의석 그림
- 본론 2: 확대 전국 지도에서 지역 이동 → 개별 접전 지역구 비교
- 참고 및 검증: 원본 근거 PDF, 선관위 최종 자료 및 개표 결과 표

## 5. 편집·데이터 원칙
선거구별 중간 득표를 최종 득표와 합성하지 않는다. 확인되지 않은 시간별 전국 개표율은 보간하지 않는다. 실제 시·도 전체 투표율과 지역구 원자료 계산 투표율은 서로 다른 표기법으로 구분한다.

## 6. 제외
영상 자동 생성, 새로운 후보 사진, 라이브 개표 연결, 2024년 당시 원본에 없는 값, 선거 예측 모형은 이번 수정 범위에 포함하지 않는다.
