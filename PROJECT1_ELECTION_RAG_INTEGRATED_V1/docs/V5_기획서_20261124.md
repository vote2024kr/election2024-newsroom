# 제22대 국회의원선거 데이터 상황실 — 최종 기획서

> 기준: GitHub `main`에 반영된 최신 3차 V5. 2026-11-24 사용자가 웹사이트를 최종 확정함. 설계안과 실제 기능, 향후 과제를 구분한다.

## 목적과 문제
2024년 제22대 총선의 검증된 **과거 시간별 투·개표 기록**과 **최종 지역구·비례 결과**를 웹에서 이해하고 데이터 저널리즘 교육·영상 자료로 활용한다. 기존 화면의 문제는 초기부터 100% 결과 노출, 전국/지역 탐색 메뉴 중복, 반복적인 막대그래프, 서로 다른 조사방식의 투표율 혼용이었다.

## 이용자와 실행
학습자·선거 데이터 독자·교육 발표자가 대상. FastAPI와 PostgreSQL `election_lab` 기반 로컬 웹사이트. 별도 정적 HTML은 검토용이다. **실시간 선관위 API·실제 뉴스 자동 송출 프로그램이 아니다.**

## 정확성과 출처
- **전국 실제 최종 67.0%**, **표본 67.2%**, **사전투표 31.3%**, **선거일 대상 표본 51.8%**를 동일 통계로 혼용하지 않는다.
- 시·도는 선관위 최종 발표 투표율, 개별 지역구는 투표수÷선거인수×100 계산값이다.
- 254 지역구·693 후보·46 비례대표 의석·총 300석. 정당명은 비례대표 명부 정당과 지역구 당선 정당 원래 이름을 유지한다.
- 미확인 시점의 지역구별 후보 득표수를 만들어 쓰지 않는다.
- **2024-04-11 10:25**는 당시 보도에 기초한 재현 화면 완료시각이며 선관위가 인증한 분 단위 종료 시각이 아니다.
- 지도는 실제 254개 선거구 경계 자료를 재사용. 네트워크/지도 파일 미확보 시 대체 이미지와 설명을 표시한다.

## 현재 결과와 제외 범위
사용자 승인에 따라 웹사이트 **최종 확정**. 정적 데이터 CG 6종은 제공된다. 실제 10~20분 MP4 영상 및 발표용 PPT 완제품이 GitHub에 존재한다는 근거는 없으므로 미제작/미등록으로 분류한다. 새로운 머신러닝 모델 학습, 벡터 DB 구축, 자동 기사 발행, 실시간 개표 연결은 완료 사항이 아니다.
