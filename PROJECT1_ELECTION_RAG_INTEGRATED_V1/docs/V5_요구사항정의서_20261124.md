# 제22대 국회의원선거 데이터 상황실 · 요구사항 정의서 (2026-11-24)

## 프로젝트 목적
2024년 제22대 국회의원선거의 **확인된 시간별 전국 투·개표 기록**과 **최종 지역구·비례대표 결과**를 학습 및 데이터 저널리즘 영상 제작에 활용한다. 과거 기록을 재생할 뿐 실시간 선관위 API와 연결하지 않는다.

## 데이터의 정의와 제한
- **최종 지역구**: 254개 선거구, 693개 후보, 최종 당선자·투표수·선거인수·득표차
- **최종 비례대표**: 정당별 배분 의석 총 46석
- **시간 기록**: 선관위 발표 및 언론 보도 시점 확인된 41개 관측 기록. 중간 지역구별 후보 득표수 미수집
- **투표율**: 실제 전국 최종 67.0%, 전국 표본 투표율 67.2%는 분모·방법이 다른 자료. 혼용 금지
- **지도**: 오마이뉴스 공개 MIT 254개 선거구 경계와 선관위 선거구 ID 연결. 세부 선거구 경계는 행정 시군구 경계가 아님
- **정당명**: 지역구 당선 정당과 비례대표 명부 정당의 법적 이름을 임의 합병하지 않는다
- **실행**: 기존 PostgreSQL의 `election_lab` 읽기. 재생 캐시는 별도 v2 테이블, 원본 기존 테이블 유지
- **보안**: DB 자격증명은 파일에 저장하지 않고 로컬호스트에서 실행

## 비기능 조건
반응형 레이아웃(데스크톱/태블릿/모바일), SVG 접근성 라벨, 서버 렌더링, 오류 시 자료 미확인 표시, 출처 유지, 미확인 수치 생성 금지, DB 원본 테이블 불변.

> 이 문서는 이번 변경사항의 수락 조건이다. Windows 사용자의 실제 PostgreSQL 접속과 모든 브라우저 해상도 시각 검증은 별도로 수행해야 한다.
