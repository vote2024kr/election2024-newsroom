## 비기능·품질 조건
1. 과거 기록을 '실시간'으로 홍보하지 않는다. 10:25를 선관위 공식 인증 종료시각이라고 단정하지 않는다.
2. 표본 67.2%와 실제 67.0%, 사전 31.3%, 선거일 표본 51.8%는 각각 다른 지표임을 구분한다.
3. DB 암호·접속정보는 GitHub나 응답 HTML에 표시하지 않는다.
4. 지리경계 확보 실패 시 결과를 꾸며 그리지 않고 대체 화면·목록 안내를 표시한다.
5. 브라우저 화면 폭에 따라 3열/2열/1열로 적응하고 버튼·SVG에 설명을 붙인다.
6. 웹페이지 최종 승인 후 이 문서 작업으로 소스·데이터·디자인을 변경하지 않는다.
