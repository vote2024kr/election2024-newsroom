# 2024 총선 데이터 상황실 · 화면 구성/설계서

## A. 2024 투·개표 상황
```
[2024년 시간대별 기록] [실시간 연결 아님]
[왼쪽: 전국 투표율·지역구·비례대표 게이지] [오른쪽: 당시 투표율 꺾은선]
[일시정지] [처음부터] [다음 시점] [5/10/15초]
[확인 시각/출처 및 방법 안내]
... 최종 2024-04-11 10:25 ...
[전국 당선 지도 + 지역구 254/비례 46/전체 300석 시각화 동시 공개]
```
- 꺾은선의 13시 **실제 관측점에만** 주황색 화살표와 '13시 · 사전투표율 포함됨'을 표시.
- 완료 전 최종 결과 숨김, 완료 후 최종 전국 결과 iframe 표시.

## B. 전국 확정 개표
```
[전국 최종 요약 · 300석 · 실제 전국 투표율]
[전국 당선 정당 지도(정적)] [지역구 254석 도넛] [비례 46석 도넛]
                             [전체 국회 300석 반원]
[정당별 지역구/비례/합계 표]
[지역·선거구 탐색 열기]
```
- 지도 자체는 지역구 드릴다운용 버튼이 아니다.
- 의석 합계는 실제 정당별 결과를 계산해 표시한다.

## C. 지역·선거구 탐색 — 승인 시안 반영
```
[전국 › 서울특별시 › 용산구]          [← 이전 단계로] [⌂ 전국 지도 보기]
┌────────────────────┬──────────────────┬──────────────────┐
│ 전국 지도 (확대)   │ 선택 지역 지도    │ 선택 선거구 결과  │
│ 17개 시·도 클릭    │ 시·도 48개 구 등 │ 당선인·정당       │
│ 기존 대비 2배+     │ 지역구별 경계     │ 후보 득표·득표차   │
│                    │                  │ 투표수/선거인수   │
└────────────────────┴──────────────────┴──────────────────┘
┌──────────────────────────┬───────────────────────────────┐
│ 시·도 선택 및 확정 투표율 │ 시·군/구 선택·지역구 목록·검색 │
└──────────────────────────┴───────────────────────────────┘
```
- 상단은 데스크톱에서 3열, 좁은 화면은 2열→1열로 순차 접힘.
- 전국 지도는 860×720 SVG 뷰박스와 넓은 그리드 컬럼을 사용, 원본 벡터를 재활용.
- 시·도 또는 지역구 선택 시 기존 동작대로 새 URL로 이동하며, 브라우저 뒤로가기와 별도로 '이전 단계로'·'전국 지도 보기' 링크 제공.
- 지역구 계산 투표율은 별도 카드이며 시·도 발표 최종 투표율과 명확하게 구분.

## D. 주요 사용자 동작
1. 전국 지도에서 경기 선택 → 경기도 지도와 선관위 최종 투표율 표시.
2. 아래 '수원시' 선택 → 수원 소속 국회의원 지역구 목록 표시.
3. 지역구 선택 → 후보별 득표수·득표율·1·2위 차이와 투표율 표시.
4. '이전 단계로' → 시·군/지역구 중 하나 상위 상태로 복귀.
5. '전국 지도 보기' → 시작 상태로 복귀.

## E. 독립성
'전국 확정 개표'는 정적 시각화. '지역·선거구 탐색'은 단계별 탐색. 같은 데이터 출처를 활용하되 메뉴 목적과 동작은 서로 다르다.
