## 2. 메인: `/safe2024?page=home`
~~~text
┌─────────────────────────────────────────────┐
│ 2024년 시간대별 기록 · 현재 실시간 연결 아님 │
├──────────────────┬──────────────────────────┤
│ 투표율·지역구·   │ 전국 투표율 꺾은선        │
│ 비례 개표율 게이지│ 13시 사전투표 합산 화살표 │
│ 5/10/15초 제어   │ 개표 중: 당선 미표시 지도 │
│ 시점 슬라이더     │ 10:25: 최종 지도+의석    │
├──────────────────┴──────────────────────────┤
│ 출처·조사방법 / 분석 화면 바로가기          │
└─────────────────────────────────────────────┘
~~~
13시 주석은 **확인된 13시 관측값이 표시될 때**에만 활성화한다. 최종 10:25는 보도 기반 재현 시각이다.

## 3. 전국 확정 개표: `page=final`
~~~text
[최종 전국 투표율·총 300석]
[전국 254개 지역구 지도] [254석 도넛] [46석 도넛]
                         [국회 300석 반원]
[정당별 지역구·비례·합계 의석 표]
~~~
전국 결과 **요약 전용**. 상세 선거구 클릭은 지역·선거구 탐색 메뉴에 분리.

## 4. 지역·선거구 탐색: `page=district`
~~~text
[전국 > 서울특별시 > 용산구]   [← 이전 단계로] [⌂ 전국 지도 보기]
┌─────────────────┬─────────────────┬─────────────────┐
│ 전국 지도 확대  │ 선택 지역 지도  │ 선택 후보 결과  │
│ 17개 시도       │ 48개 등 선거구  │ 당선인·정당     │
│ 시도 선택/강조  │ 실제 경계 색상   │ 표수·득표율·표차│
│                 │                 │ 지역구 투표율   │
└─────────────────┴─────────────────┴─────────────────┘
┌────────────────────────┬────────────────────────────┐
│ 시·도 선택 목록         │ 시·군/지역구 목록·검색     │
└────────────────────────┴────────────────────────────┘
~~~
실제 클래스 `explore-grid`(상단)와 `explore-bottom-grid`(하단) 기준. 시·군은 **선거구명으로 만든 검색 분류**이며 행정경계 지도와 다르다. 지역구의 계산 투표율은 분자·분모 병기.

## 5. 기타 화면
- 비례대표: 전국/지역별 득표·정당 의석
- 투표율: 전국 실제 67.0%, 사전 31.3%, 선거일 **표본 51.8%**, 시도별 색상·성별/연령 조사방식별 구분
- 개표 분석: 정당별 의석과 접전 선거구 표차
- 사진·영상 자료: 선관위 관련 실제 결과로 제작된 **정적 데이터 CG 6종**, MP4 미등록

## 6. 화면 이동 점검
전국→경기→수원시→수원시정 선택→후보 득표/투표율 확인→이전 단계→전국 지도로 이동. 지리경계 파일 실패 시 안내용 사진/타일과 목록 탐색을 구분하여 표기한다.
