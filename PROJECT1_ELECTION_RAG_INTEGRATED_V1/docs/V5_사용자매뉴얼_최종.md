# V5 사용자 매뉴얼 — 비개발자용

## 1. 웹사이트 실행
**운영용:** 기존 프로젝트 폴더의 `RUN_POSTGRES_NEWSROOM.cmd`. PostgreSQL `Election2024` 서버와 기존 설정된 DB가 필요하다. 시작 과정에서 시간별 재생용 `historical_replay_2024_v2` 테이블을 다시 채울 수 있으므로 완전한 DB 읽기 전용 실행이 아니다.

**검토용:** `V5_2차_웹사이트_검토실행.cmd`로 별도 데이터 사본 기반 디자인을 확인하거나, `V5_3차_브라우저_미리보기.html` 파일을 더블클릭해 독립 화면을 살펴본다. 검토용은 운영 PostgreSQL 최종 검증을 대신하지 않는다.

Windows 경로가 너무 길면 `psycopg_binary._psycopg` DLL 로드 오류가 날 수 있다. 이전에 '파일 이름이나 확장명이 너무 깁니다' 오류가 보고됐으므로 프로젝트 경로 길이와 해당 `.venv` 환경을 확인한다. **암호 오류라고 단정하지 않는다.**

## 2. 메뉴 사용
- **2024 투·개표 상황:** 왼쪽 게이지와 오른쪽 그래프. 일시정지·처음부터·다음 시점·시점 직접 선택. 5/10/15초로 속도 변경.
- **전국 확정 개표:** 확정 지도·도넛·반원·의석 합계. 전국 판세를 한 화면에서 확인.
- **지역·선거구 탐색:** 전국 지도에서 시·도 클릭→시·군 목록 클릭→지역구 선택→후보별 표수와 투표율 확인. '이전 단계로' 또는 '전국 지도 보기'로 복귀.
- **비례대표 개표:** 정당·지역별 비례대표 최종 자료.
- **투표율 분석:** 실제 시도 최종 집계와 표본·전수조사 지표를 구분해서 본다.
- **개표 분석:** 근소 표차 지역구·의석 그래프.
- **기사 초안·검증 / RAG 근거 질문:** 교육용 자료 검토. AI 완성 기사로 오인하지 않는다.
- **방송 CG·대본 / 공식 결과 CSV:** 시각화·원본 자료 내보내기.
- **보도자료·학습데이터 / 사진·영상 자료:** 실습 자료와 6개 정적 데이터 CG 열람.

## 4. 문제가 있을 때
1. 사이트가 안 열림 → `RUN_POSTGRES_NEWSROOM.cmd` 실행창 오류 확인, 로컬 주소·포트 확인
2. PostgreSQL 오류 → 실행 여부·DB명·포트·권한 확인. 비밀번호를 문서/채팅에 붙여넣지 않는다
3. `ImportError: DLL load failed` → `psycopg` 드라이버/Windows DLL/긴 파일 경로 검사, 단순 암호 오류 아님
4. 지도가 대체 이미지 → 원본 254개 지리경계 파일의 최초 다운로드/저장 여부 확인
5. 시간별 화면이 갱신되지 않음 → 운영 DB 41시점 기록·브라우저 콘솔·재생 일시정지 상태 확인
6. PDF/CSV 화면이 안 나옴 → `newsroom/real_data/` 원본 및 파일 권한 확인
7. 영상 메뉴에 MP4가 없음 → 현재 등록된 것은 PNG CG 6종이며 동영상 업로드 완료를 뜻하지 않음

## 5. 데이터 출처 확인
각 시간 시점의 기사/선관위 링크, 조사방법 발췌 PDF, 지역구 엑셀 원본 행, CSV 자료를 같이 확인한다. 중간 단계의 후보별 표가 없는 경우 임의 산출하지 않는다.
