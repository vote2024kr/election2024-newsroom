# 선거구 지도 데이터 저작권 및 근거

- 2024년 22대 총선 254개 지역구 경계: 오마이뉴스 [`2024_22_elec_map`](https://github.com/OhmyNews/2024_22_elec_map)
- 지도 소스: `2024_22_Elec_simplify.json`
- 라이선스: MIT (아래 원문 보존)
- 앱 배포용 파일은 선거구 경계와 기존 V5 지역구 ID를 정확히 254대254로 연결했으며 좌표는 소수점 다섯째 자리로 반올림했습니다.
- 선거 결과 득표수·득표율은 이 지도 파일에서 가져오지 않고 기존 선관위 V5 PostgreSQL 데이터에서 조회합니다.
