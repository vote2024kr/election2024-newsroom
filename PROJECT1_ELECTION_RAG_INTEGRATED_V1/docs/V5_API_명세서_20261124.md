# V5 · 화면/API 명세서 (FastAPI)

기본 주소: `http://127.0.0.1:8541` (실행 스크립트 설정에 따라 실제 포트 확인)
출력 자료는 PostgreSQL `election_lab` 기반. 실시간 선관위 API 호출 없음.

| 메서드 | 경로 | 요청변수 | 출력 | 중요 규칙 |
|---|---|---|---|---|
| GET | `/safe2024` | `page=home` | 2024 시간별 재생 HTML | 첫 화면에서 전국 최종 자료 전량 조회 방지 |
| GET | `/safe2024` | `page=final` | 전국 확정 결과 HTML, 254석·46석 도넛, 300석 반원 | 정적 전국 요약 |
| GET | `/safe2024` | `page=district&region=경기도` | 전국/선택 시도 지도, 하단 시군 목록 | 선택 지역만 필터 |
| GET | `/safe2024` | `page=district&region=경기도&area=수원시` | 선택 도시 소속 선거구 검색 | 선거구명 기반 탐색용 분류 |
| GET | `/safe2024` | `page=district&region=경기도&district=C119` | 후보 최종 득표와 지역구 투표율 | `registered`/ `ballots` 검증 |
| GET | `/safe2024` | `page=turnout` | 실제/표본 지역·연령·성별 투표율 | 조사 방법을 구별 |
| GET | `/safe2024` | `page=pr` | 비례대표 전국/지역 결과 | 기존 유지 |
| GET | `/safe2024/final-embed` | 없음 | 완료 시점에서만 조회하는 전국 확정 지도 및 의석 그래프 | 프런트 10:25 이전 요청 금지 |
| GET | `/safe2024/map` | `region=경기&district=C119` | 기존 지도 UI | 기존 엔드포인트 보존 |
| GET | `/safe2024/api/replay/{index}` | `index=0..40` | 당시 관측 시점 JSON | 관측하지 않은 시점 생성 금지 |
| GET | `/safe2024/turnout-methodology.pdf` | 없음 | 선관위 조사방법 PDF 발췌 | 기존 유지 |
| GET | `/safe2024/export` | `kind` | 공식 결과 CSV | 기존 유지 |

### 응답 출처
- `/safe2024/api/replay/{index}`: `observation_id,time,phase,series,turnout,counting,proportional,counting_asof,proportional_asof,source,source_label,note` 등을 포함한다.
- `/safe2024?page=district`: 최종 DB 결과와 SVG 지도는 254개 ID 대조 뒤 출력.
- 비밀번호·DB DSN·인증 자료는 HTML 및 API로 반환하지 않는다.

### 오류 원칙
미지의 시점은 404, PostgreSQL 미연결 또는 선거구 지도 불일치는 503/원인 범위 안내. 서버 내부 경로 및 DB 비밀번호 노출 금지.
