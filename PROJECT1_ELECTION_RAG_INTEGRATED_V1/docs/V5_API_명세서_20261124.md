# V5 최종 API 및 화면 경로 명세

## 기본
현재 FastAPI 앱: `project1_app.py` → `newsroom_safe2024.bind_safe()`. 로컬 기본 포트는 실행기 설정을 우선한다. 이 문서의 요청 예시는 **로컬호스트 `http://127.0.0.1:8541` 기준**이다.

| 방식 | 요청 경로 | 입력/응답 | 근거 |
|---|---|---|---|
| GET | `/safe2024?page=home` | 41개 과거 기록 재생 HTML. 초기 화면에서 무거운 최종 DB 로드를 피함 | `replay_html()` |
| GET | `/safe2024?page=final` | 최종 전국 지도·254/46/300석·의석 표 | `final_summary()` |
| GET | `/safe2024?page=district&region=경기도` | 시도 지도 + 지역 선택 목록 | `district_explorer()` |
| GET | `/safe2024?page=district&region=경기도&area=수원시` | 시·군 지역구 그룹 선택 | `district_explorer()` |
| GET | `/safe2024?page=district&region=경기도&district=C119` | 최종 후보·표수·투표율·표차 | `district_explorer()` |

## 응답·오류 규칙
- `api/replay/{index}`는 `id`·`time`·`phase`·`series`·`turnout`·`counting`·`proportional`·`counting_asof`·`proportional_asof`·`source`·`source_label`·`note` 등 당시 관측 정보를 포함한다.
- `/safe2024`의 최종 결과 메뉴는 PostgreSQL 연결이 없으면 서버가 **503 오류 화면**을 반환하며 JSON 자료로 몰래 대체하지 않는다.
- 지도 `mode` 허용 값: `results`·`outline`, 그 밖의 값은 422.
- CSV `kind` 허용 값: `district`·`proportional`·`turnout`, 그 밖의 값은 422.
- 정적 CG는 허용된 6개 파일명 외 404.
- PostgreSQL 비밀번호나 DB 연결 문구 전체를 응답에 표시하지 않는다.

## 기존 별도 학습 기능
`/project1`·`/workbench/`·뉴스룸의 모의 WebSocket 등은 **서로 다른 교육용 앱**으로 현행 V5 선거 최종 데이터 API와 혼용하지 않는다.
