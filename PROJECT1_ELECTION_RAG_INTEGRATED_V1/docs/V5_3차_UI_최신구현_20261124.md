# V5 최신 3차 UI — 최종 구현·승인 기록

## 기준
- 사용자가 제공하고 최종 확정한 **3차 V5 전체 소스**가 기준. 과거 구버전과 일부 UI가 결합된 중간 커밋은 기준이 아니다.
- 현행 사용 모듈: `newsroom_safe2024.py`, `newsroom_district_explorer2024.py`, `newsroom_visuals2024.py`, `newsroom_replay2024.py`.
- 이전 임시 설계의 `newsroom_election_layout_v2.py`를 현행 코드라고 기록하는 것은 잘못이다.

## 최종 화면 배치
| 영역 | 확정 내용 |
|---|---|
| 상단 왼쪽 | **전국 17개 시·도 지도 확대**. 선택 시·도를 지도에서 클릭 |
| 상단 가운데 | **선택 시·도 지역구 지도**. 당선 정당별 색상, 지역구 클릭 |
| 상단 오른쪽 | **선택 지역구 확정 결과**. 당선인·득표율·지역구 투표율·후보 득표 및 표차 |
| 하단 왼쪽 | 시·도 선택 목록과 실제 시·도 최종 투표율 |
| 하단 오른쪽 | 시·군/구 명칭 기반 지역구 목록·선택·검색 |
| 상단 이동 | '← 이전 단계로', '⌂ 전국 지도 보기' |
| 반응형 | 데스크톱 3열/2열, 좁은 화면 줄바꿈 |

## 다른 메뉴에서 보존된 기능
1. **2024 투·개표 상황:** 41개 확인 시점, 13시 사전투표 포함 화살표, 10:25 보도 기준 최종 동시 공개
2. **전국 확정 개표:** 전국 지도, 254/46석 도넛, 300석 반원. 지역구 탐색과 독립
3. **투표율 분석:** 17개 시·도 실제 투표율 지도 및 순위, 연령·성별 조사방법 구분·교차분석
4. **개표 분석:** 정당별 의석과 근소 표차
5. **사진·영상 자료:** 데이터 CG **6종 PNG**, 동영상 미등록
6. **기존 RAG·기사·CSV·Workbench/모의 개표** 보존

## 검증 이력
확정 코드와 GitHub 핵심 파일 SHA 일치 확인. 관련 자동 테스트 17개 재실행 통과. 이 검증은 Windows PostgreSQL 실환경 전체 정상 작동을 확정하는 것은 아니다.
