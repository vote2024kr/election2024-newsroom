# 발표자료(PPT) 슬라이드 구성안 — 웹사이트 최종 버전

> 실제 `.pptx` 파일이 아니라 **발표자가 바로 제작할 수 있는 슬라이드 원고**. 10~15분 내외 발표 기준(시간은 제안이며 확정 일정 아님).

| 슬라이드 | 제목 | 화면에 넣을 근거·이미지 | 발표 핵심 |
|---|---|---|---|
| 1 | 2024년 제22대 총선 데이터 상황실 | 메인 최종 타이틀 | 과거 실측·보도 기록을 재생하는 교육 프로젝트 |
| 2 | 문제와 개선 방향 | 이전 전체 100% 화면 vs 시간 재생 | 실제 당시 기록의 흐름 표현 |
| 3 | 자료 출처 | 중앙선관위 공식 개표·투표율 분석 출처 | 실제 집계와 표본조사 구분 |
| 4 | 데이터 구조 | 254 지역구·693 후보·46 비례·300석 | 실제 PostgreSQL·검산 |
| 5 | 시스템 구성 | [아키텍처](V5_시스템아키텍처_20261124.md) Mermaid | FastAPI·PostgreSQL·SVG·기존 모의기능 분리 |
| 6 | 시간별 투표율 | 13시 사전투표 포함 화살표 화면 | 13시 이후 포함 방식 변경, 실시간이 아닌 역사 재생 |
| 7 | 개표 진행 | 지역구·비례 개표율 게이지 | 확인된 관측 지점만 사용 |
| 8 | 전국 최종 결과 | 전국 당선 지도·254/46/300석 시각화 | 선거 전체 구조 |
| 9 | 지역 상세 탐색 | 상단 전국/지역/결과 3열, 하단 선택/검색 2열 | 실제 지역구 후보별 표·투표율 |
| 10 | 투표율 조사방법 | 실제 67.0 / 표본 67.2 / 사전 31.3 / 선거일 표본 51.8 | 다른 분모·조사방법 혼용 방지 |
| 11 | 검증 결과 | 17개 자동 테스트 + 한계 | 소스 검증과 Windows 운영 검증 구분 |
| 12 | 결과·확장 과제 | 웹사이트 최종 확정과 미완성 영상·AI 모델 항목 | 완료된 것과 미완료 항목의 정확한 분리 |

## 발표할 때 피해야 할 표현
- '실시간 선거 결과를 받아온다' → **2024년 당시 확인 기록을 일정 간격으로 재생한다**
- '10시25분 선관위 공식 종료' → **당시 보도 기준으로 정한 재현용 종료시각**
- 'AI 모델이 학습해 판정을 내렸다' → 기존 교육용 TF-IDF/근거 검색과 실제 모델 훈련은 별개
- '51.8% 실제 본투표율' → **선거일 대상 표본조사 투표율**
