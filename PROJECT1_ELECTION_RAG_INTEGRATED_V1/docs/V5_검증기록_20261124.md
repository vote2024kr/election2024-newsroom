## 코드에 내장된 검증
1. 지도 254개 ID가 선거구 결과 254개 ID와 일치하는지 검사. 틀리면 거짓 지도를 그리지 않고 중단
2. 지역구 의석 254석/비례 46석, 전체 300석 합계 불일치 시 에러
3. 지역구 투표율은 양의 선거인수 및 유효 범위 투표수일 때만 계산
4. 선택 시·군구 외 선거구 클릭 시 기존 시군 필터를 해제해 상세 결과를 숨기지 않음
5. 시간 선그래프는 기록에 실제 2024-04-10 13:00 점이 존재하는 경우에만 화살표 생성
6. 마지막 기록이 지역구·비례대표 모두 100%일 때만 전국 확정 요약 URL 조회

### 사용자 PC 검증 순서
1. `RUN_POSTGRES_NEWSROOM.cmd`로 DB 연결 후 `/safe2024?page=final` 열기
2. 전국 254색 지도와 254·46·300 의석 합계 확인
3. `/safe2024?page=district`에서 전국→서울→용산구 클릭 후 후보·투표율 확인
4. '이전 단계로'와 '전국 지도 보기' 링크 동작 점검
5. 시간별 재생에서 13시 실제 점에 화살표가 나타나는지 확인
6. 10:25 이전에는 최종 결과가 나타나지 않고 마지막 시점에만 전국 요약이 표시되는지 확인
7. 테스트: `python -m pytest -q tests/test_replay2024.py tests/test_v5_layout_20261124.py`
