## 핵심 8종 확인
교육표의 핵심은 **기획서·요구사항 정의서·ERD·화면 설계서·API 명세서·소스코드(GitHub)·발표자료(PPT)·시연 영상**이다. 앞의 6종은 파일/문서로 확인되며, PPT·영상은 **원고/구성안만 제작**됐고 실제 제출 파일은 완료 표시하지 않는다.

## AI 프로젝트 추가 산출물
| 교육표 추가항목 | 현재 판단 |
|---|---|
| AI 모델 파일(`.pkl` / `.h5`) | 별도 모델 훈련 산출물 확인 안 됨. **임의 모델 파일 생성 금지** |
| 학습 데이터셋 | 기존 교육용 문서·보도자료·JSONL/CSV 자료 존재. **실제 모델 학습 세트라는 증거와 구별** |
| 모델 성능 평가 보고서 | 학습 모델이 없으므로 정확도/재현율 등 모델 평가 실측은 없음 |
| 프롬프트 설계서 | [프롬프트·RAG 범위 문서](V5_AI_RAG_산출물_현황_최종.md)에 실제/미구현 구분 |
| RAG 문서 | 교육용 문서·TF-IDF 근거 검색 존재. 생성형 LLM RAG 완료로 표시하지 않음 |
| 벡터 DB 설계서 | 현재 운영 벡터 DB 없음. 해당 문서에서 **도입 가능성 설계**만 분리해 기재 |
