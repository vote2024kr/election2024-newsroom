# V5 최종 프로젝트 보고서

## 1. 프로젝트
**2024년 22대 국회의원 선거 시간대별 투·개표 현황**. 2024년 당시의 검증된 관측 기록과 최종 공식 데이터를 활용해 투표율·개표 과정·당선 결과를 단계적으로 전달하는 교육용 데이터 저널리즘 웹사이트.

**웹사이트 상태:** 2026-11-24 사용자가 최신 3차 구현 화면을 최종 확정. 저장소 `main`에서 확인.

## 2. 수행 결과
- 기획: 시각별 기록과 최종 결과·상세 지역 탐색의 목적을 구분
- 설계: 전국 확정 개표(요약)와 지역구 탐색(심층)을 분리. 상단 3열/하단 2열 지도 화면 최종 승인
- 구현: 41개 과거 관측 시점 재생, 13시 사전투표 반영, 10:25 최종 동시 공개, 실제 최종 당선 지도와 254/46/300석 의석 시각화
- 검증: 확정 소스 ZIP과 GitHub 주요 코드 해시 대조, 4개 핵심 테스트 모음 **17건 통과**
- 자료: 6종 정적 데이터 CG, 지역구·비례·투표율 CSV, 조사방법 PDF, 지리경계 출처 기록

## 3. 기술 구성
- 프런트: HTML/CSS/JavaScript, SVG 지도, 지도·도넛·반원 그래프
- 서버: Python/FastAPI `project1_app.py`, `newsroom_safe2024.py`
- 최종자료: PostgreSQL `election_lab`, `newsroom/postgres_data.py` 검산
- 시간 재생: `newsroom_replay2024.py`·`historical_replay_2024_v2`
- 선택 지역: `newsroom_district_explorer2024.py`
- 교육용 별도 기능: 모의 뉴스룸, TF-IDF 문서 검색, 기사 초안 검증, 통계 워크벤치

## 6. 완료 여부의 정확한 구분
- **최종 확정:** 웹 대시보드, 현재 확정 버전의 구현과 화면 구조
- **확인된 산출물:** Python 소스, SQL/로컬 파일, GitHub 저장소, 요구사항·설계·검증 문서, CG 6개

- **구현 완료로 주장하지 않음:** 별도 `.pkl`/`.h5` 학습 모델, 모델 평가 보고서, 운영 벡터 DB

## 7. 결론
전국 선거 결과를 **시간별 변화 → 전국 최종 요약 → 시·도·지역구 심층 탐색**으로 읽을 수 있도록 정보구조를 구분했고 실제 최종 결과와 교육용 모의 데이터를 분리했다. 영상·PPT 등 제출 산출물의 완성 여부는 웹사이트 승인과 별개로 확인해야 한다.
