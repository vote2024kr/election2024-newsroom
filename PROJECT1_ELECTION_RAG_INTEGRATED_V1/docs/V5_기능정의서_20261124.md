# V5 기능정의서 · 제22대 국회의원선거 데이터 상황실 (2026-11-24)

## 목적
과거 시각별 전국 투·개표 기록을 재생하고 2024년 제22대 총선 최종 결과를 전국 요약과 지역구별 상세 탐색으로 **명확하게 분리**하는 웹 대시보드.

## 주요 오류 처리
- 실제 지도 GeoJSON 254개 ID와 결과 254개 ID가 다르면 지도를 **오류로 중단**하고 가짜 경계를 그리지 않는다
- 후보별 중간 득표 기록이 없는 시각에는 최종 표수를 시간별 데이터로 오인해 표시하지 않는다
- 투표율은 선거인수>0, 0≤투표수≤선거인수에만 계산한다
- PostgreSQL 연결/실제 Windows DLL 환경은 자동으로 해결됐다고 간주하지 않는다
- 실시간 선관위 API나 외부 LIVE 데이터로 오표기하지 않는다
