## 4. 공통 데이터 유효성
- `newsroom/postgres_data.py`에서 최종 자료와 SQL 행 수를 대조한다. 지역구 254건, 후보 693건, 비례 지역 253건, 지역별 비례 정당 9,614건, 전국 비례 정당 38건, 시도 요약 17건, 투표율 106건, 출처 문서 2건.
- 후보 득표 합계 = 유효 투표수, 당선자 = 후보 명단 내 일치 인물, 지도 ID 254개 상호 일치.
- 정당 색은 화면 보조 수단이고 정보 출처를 대체하지 않는다.
- DB/지도 자료 미준비 시 없는 값을 표시하지 않는다.
