# 프로젝트 1 시연 시나리오 · 교육용

## A. 정상 보도 흐름
1. `START_PROJECT1_WINDOWS.bat`를 실행하고 `/project1` 접속.
2. WebSocket 실시간 모의 값 확인 → `일시정지` 선택 (동시 개표 단계 변경으로 인한 승인지연 방지).
3. `문서 검색`에서 편집자 승인·근거 ID 검색, DEMO-G 문서 반환 확인.
4. `정상: 근거 일치` 선택 → 기사 초안 생성.
5. 기사 표수·지역·근거 ID 확인 후 편집자 식별자·승인 사유 입력 → 로컬 교육용 승인.
6. 감사 이력에서 CREATED 및 APPROVED_LOCAL_CLASSROOM 확인.

## B. 카오스 보도 — 오류 자동 차단
1. `오류: 표수 변경` → 생성 → 승인 누르기 → HTTP 409(검증 실패).
2. `오류: 지역 변경` → 동일하게 차단.
3. `오류: 근거 ID 삭제` → 동일하게 차단.
4. 정상 기사를 만든 뒤 `개표 1단계 진행` → 이전 근거로 승인 시 `기준 단계 변경` 차단.

## C. 통계툴 연계
1. `현재 결과 CSV → 분석툴 전달` 버튼 클릭. 기본 자료는 교육용 17개 시도/68개 가상 선거구의 최종 수치 **204개 후보-선거구 행**.
2. `통합 통계툴 열기`에서 데이터 이름·출처/미검증 상태 확인.
3. `집단별 요약` 기법, 그룹=`region`, 수치 변수=`votes`, 집계=`합계` 선택 → 지역별 막대그래프.
4. 후보 비교 시 선거구 단위로만 득표율을 계산하고, 후보 이름이 같은 경우에도 전국 단일 후보로 합산하지 않기.
5. CSV 또는 JSON으로 분석결과 다운로드.

## D. 업로드한 최종 선거 결과와의 차이
1. 기존 뉴스룸 `/` → `공식 결과 CSV 분석` 메뉴.
2. 선관위 공개 원본은 사용자가 직접 내려받아 업로드. URL/선거명 입력은 원본을 공식 인증하지 않음.
3. 후보자/투표수 등 혼합 행, 합계 행, 중복키 검사 후 집계.
4. `/project1`로 이동해 통계툴로 전달. 자료 출처는 `사용자 업로드 · 공식성 미검증`으로 표시.
5. 시간별 투표 증감·실제 개표 단계 변화는 원본에 없으면 계산하지 않기.
