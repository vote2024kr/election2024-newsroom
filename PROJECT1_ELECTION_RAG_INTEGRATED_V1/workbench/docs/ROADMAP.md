# 통합 통계툴 개발 순서

## V1.0 — 이번 패키지
- 17종 공통 통계기법, 파일 업로드/품질 진단, 조건 선택, SVG 그래프+결과표, CSV/JSON 저장.
- 4가지 가상 샘플. Windows 더블클릭 `.bat` 실행.
- 기존 통계기법 AI V1.2와 NEWSROOM LAB V0.7 ZIP을 원본 보존.

## V1.1 — 다음 통합 작업
- **기존 통계기법 AI 추천 엔진을 API 어댑터로 결합**: RAM/용량에 따른 pandas/Polars/Dask 추천.
- **선거 통계 모듈 연결**: 실측과 모의를 별도 데이터 모드로 구분, 원본 출처/기준시각 필수.
- 저장한 분석 설정·그래프 구성 다시 불러오기, 다중 결과 비교, 데이터 사전·버전 관리.
- E2E Windows 브라우저에서 클릭·파일 불러오기·그래프 생성 실제 검증.

## V1.2 — 확장
- DB 기반 프로젝트별 데이터·기법·실행 이력/권한, 플러그인 등록 SDK.
- 환경/매출/뉴스/선거 외 분야별 데이터 매핑 템플릿.
- Dask·Polars 대용량 처리, 시계열 분할 검증, 교차검증·다중검정 보정, 모델 관리.
- 공식 데이터 수집은 출처·라이선스·갱신 정책 검증 후 연결.
