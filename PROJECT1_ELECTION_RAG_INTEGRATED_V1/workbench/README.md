# 통합 통계 가공·분석 시스템 V1.0 — Windows 로컬 실행 패키지

> **현재 상태:** 독립적인 1차 통합 MVP. 사용자 업로드 CSV/XLSX/JSON/JSONL을 분석하며, 17종 계산법·조건 필터·표·SVG 그래프·실행 이력을 제공합니다. 기존 NEWSROOM LAB 및 통계기법 AI 원본 ZIP은 `legacy/`에 수정 없이 보관합니다. **GitHub 업로드 없음.**

## 바로 실행하기 (Windows 11)

1. ZIP을 **새 폴더**에 압축 풀기. 예: `C:\workspace\Unified_Statistics_Workbench_V1_0`.
2. `START_WINDOWS.bat` 더블클릭. 첫 실행은 Python 3.12·인터넷(패키지 설치)이 필요합니다.
3. 브라우저 자동 열림. 열리지 않으면 `http://127.0.0.1:8530` 직접 입력.
4. 샘플 4개 중 하나 선택 또는 CSV·XLSX·JSON·JSONL 업로드.
5. **데이터 유형 → 통계기법 → 필요한 변수 → 필터 → 계산하기** 순서로 실행.
6. 결과를 보기 전에도 **가공 데이터 CSV 저장**에서 조건 필터·중복 제거·결측 정책·`X+Y`, `X-Y`, `X/Y`, `X/Y×100` 계산 열을 선택해 가공된 데이터를 내려받을 수 있습니다. **원본은 바뀌지 않습니다.**
7. 그래프·요약카드·근거표를 확인하고 **결과 CSV/JSON** 저장. 종료는 콘솔에서 `Ctrl+C`.

시작 화면은 *교육용 모의 선거 데이터*로 자동 계산되어 처음부터 그래프가 나타납니다. 실제 자료가 아닌 경우 늘 `가상 샘플 데이터`로 표시됩니다.

### PowerShell 수동 실행

```powershell
cd C:\workspace\Unified_Statistics_Workbench_V1_0
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

Windows에서 `py -3.12` 명령을 찾지 못하면 Python 3.12 설치 상태를 점검하세요. `tzdata`를 의존성에 포함해 이전 `Asia/Seoul` 시간대 오류가 재발하지 않도록 했습니다. `.bat` 차단 시 PowerShell 수동 실행을 이용하세요.

### 테스트

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

| 파일 | UTF-8/CP949 CSV, XLSX, JSON, JSONL 업로드·기본 검사 | 동작 |

| 분석 | 기술통계·빈도·집단 비교·추세·상관·회귀·검정·부트스트랩·군집·PCA·텍스트·선거 분석 등 **17종** | 동작 |

| 기존 프로젝트 | 통계기법 AI V1.2, NEWSROOM LAB V0.7 원본 ZIP 별도 보존 | 포함(레거시) |
| 통합되지 않은 기능 | NEWSROOM 기존 방송 화면·RAG 기사 편집·승인, 독립 영상·CG·자동 외부 크롤링, 실제 개표 피드, 대용량 분산처리 | **미연결** |

기존 프로젝트 전체를 하나의 실행창에 무리하게 끼워 넣으면 기존 UI와 검수 규칙이 훼손될 수 있어, 우선 **데이터 분석에 공통으로 사용할 수 있는 계산층**을 통합했습니다. `legacy/` 원본은 독립적으로 실행할 수 있습니다. 다음 단계에서 API 어댑터로 통합하되 원래 화면과 상태를 유지하는 방향입니다.

## 기법 분류 (17종)

**데이터 점검·요약:** 결측/중복 진단, 기술통계, 빈도/비율, 그룹별 비교, 히스토그램  
**시간·관계:** 시계열/이동평균, 상관, 단순 선형회귀  
**검정·확률:** Welch t 검정, 카이제곱 독립성 검정, 부트스트랩 평균 구간  
**AI/텍스트:** KMeans, PCA, 단어 빈도  
**선거:** 후보별 득표율, 선거구별 1·2위 격차(%p), 단계별 개표율

각 기법에 필요한 열·주의점이 UI와 `docs/METHOD_MATRIX.csv`에 있습니다. 통계 유의확률의 사용과 대표성/독립성/데이터 품질은 사용자가 확인해야 합니다. 모의 선거는 예측·실제 결과로 해석하지 마세요.

## 설계 구조와 자료 보존

`app/engine.py`가 통계 계산을, `app/server.py`가 데이터 업로드와 분석 API를, `app/static`이 UI를 담당합니다. ERD는 **향후 영속 DB 확장 설계안**이고, 현재 실제 DB는 없습니다. 데이터와 실행 이력은 서버 메모리에만 있으며 재시작하면 사라집니다.

**보안:** 인증 없이 로컬 PC에서만 이용하는 개발용 프로그램입니다. 기본 서버는 `127.0.0.1`에만 연결됩니다. 외부 인터넷에 공개하지 마세요. 업로드 파일은 메모리의 최근 5개 데이터세트로만 보관하고 원본을 디스크에 저장하지 않습니다. 브라우저에서 내려받은 파일의 저장 위치는 사용자가 선택합니다.

**CSV/그래프 한계:** 결과표 최대 500행(결과 CSV도 해당 표시 행만 저장), 막대 차트 최대 40항목, 산점도 최대 350점, 업로드 파일 최대 12MiB·50,000행·120열, 한 번에 분석 시나리오 20회 이력. 대용량/외부 데이터/실시간 스트리밍은 별도 단계입니다.
