# NEWSROOM LAB — 제22대 총선 원본 근거·검수 기능 개선판

## 설치 (정리본)

이미 패치가 적용되어 있습니다. `00_처음실행_정리본.md`를 참고하여 Python 3.12 설치 후 `뉴스룸_실행_한글.bat`를 실행하세요. 최초 실행은 필요한 가상환경과 패키지를 설치합니다. 종료는 `뉴스룸_종료_한글.bat`를 사용합니다. 화면이 이전 모습이면 Ctrl + Shift + R로 새로고침하세요.

## 수정한 항목

- **프로젝트 1 통합운영실**: 기본은 `2024 실제 확정 결과`; 기존 모의 개표는 버튼으로 전환하고 원본 그대로 유지합니다.
- **RAG 기사·검증**: 실제 확인된 선관위 통계 수치로 제목·리드·본문 초안을 만들고 편집자 검토·승인을 분리합니다. 수치 삭제나 미검증 수정 시 승인 불가로 처리합니다.
- **자유 질문**: 직접 입력한 질문을 중앙선관위 보고서의 확인된 항목과 대조합니다. **자료에 없으면 '확인 불가'**라고 답합니다.
- **투표율 표현**: `1,505개 투표구`(선거구 아님), 선거일 투표율 51.8%의 분모, 전체 표본·사전·국외부재자·재외선거인 각 전수조사 구분을 표시합니다.
- **지역구·비례대표**: 의석수는 `254 + 46 = 300`으로 구분합니다. `비례대표 구·시·군 집계행 253개`는 `지역구 254개 선거구`와 다른 집계 단위입니다. 원본 누락이 없는지는 별도 검산이 필요합니다.
- **출처 표기**: 자료 생산 기관은 **중앙선거관리위원회**입니다. 전달자에게 출처를 돌리지 않습니다.
- **기존 기능**: 전국 개표 대시보드, 지역구·비례 그래프, CSV 업로드, 방송 CG, 모의 실시간 개표, 기존 PDF·기사 자료는 삭제하지 않습니다.

## 주의 및 한계

이 패치는 **기존 최신 프로젝트에 덧붙이는 방식**입니다. 과거 ZIP을 강제로 덮어쓰지 않습니다. 현재 이 작업 환경에 실제 개표 XLSX와 최신 프로젝트 ZIP이 함께 존재하지 않아 **최신 실행본 전체와의 통합 동작을 직접 검증했다고 주장할 수는 없습니다.** 기존에 PC에 들어 있는 실제 개표데이터는 유지됩니다. 원문 PDF는 이 패치에 포함되어 있습니다.

표본·전수 통계 수치 및 보고서 페이지는 원본 PDF로 대조했습니다. 정당별 의석 결과는 선관위 발표를 인용한 2024년 4월 11일 당시 보도와 교차 확인했습니다. 이 패치의 질의응답은 **LLM·벡터 검색 기반 RAG가 아니라 근거 원문에 연결한 규칙 기반 질의응답**입니다. 외부 LLM을 연결했다고 표시하지 않습니다.

수정된 프런트엔드 화면에서 답변이 없는 질문은 추측하지 않습니다. 개표시간별 변화 자료가 없으므로 실제 확정 결과를 시간별로 조작하거나 재생하지 않습니다.


## 2026-11-14 인코딩 오류 수정

- 앞선 패치의 한글 배치파일 내용이 Windows CMD에서 깨져 `패치_적용.py` 파일을 찾지 못하는 문제가 있었습니다. **사용자 설치 방법의 문제가 아닙니다.**

- 실행되는 Python 파일은 `patch_apply.py`, `newsroom_launch.py`, `newsroom_stop.py` 등 영문 파일명이며 화면 안내는 한글입니다.
- **기존 NEWSROOM 프로젝트 폴더와 CSV/PDF를 삭제하지 마세요.** 이전 패치 폴더가 남아 있더라도 새 ZIP의 `패치_적용.bat`만 사용하세요.
