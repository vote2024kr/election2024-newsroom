NEWSROOM LAB · PostgreSQL 브라우저 응답 없음 개선판 V3

실행 방법
1) 기존 V2는 그대로 보관하고 뉴스룸_종료_한글.bat로 종료합니다.
2) V3 압축을 별도 새 폴더에 풀고 RUN_POSTGRES_NEWSROOM.cmd를 실행합니다.
3) 기존 데이터베이스 Election2024에 접속합니다. 데이터는 다시 입력하지 않습니다.
4) 브라우저에서 Ctrl+Shift+R 새로고침 후 개표 완료 100%, 전국 투표율 67.0%를 확인합니다.

변경 사항
- 첫 화면에 필요한 2024 확정 결과만 우선 그림. 다른 메뉴는 클릭할 때 생성.
- 추가 패치의 화면 전체 텍스트 반복 감시가 실제 데이터 화면에서는 작동하지 않도록 변경.
- 기존 모의 개표, RAG 질의응답, 통계, 출처, UI, 데이터와 PostgreSQL 경로 보존.
- 브라우저 캐시를 피하도록 수정한 JS의 버전값 변경.

검증
- 로컬 브라우저: 동일 구조 2024 선거 JSON 응답을 PostgreSQL 방식으로 모의해 화면 표시와 메뉴 전환 검사 통과.
- 자동 테스트: NEWSROOM 60개 + Workbench 44개 + 통합 25개 = 129개 통과.
- 실제 Windows Chrome과 사용자 PC PostgreSQL의 결합 환경에서는 아직 재현 시험을 하지 못했습니다.
- 원인 하나를 확정한 것은 아니며 위의 실행부 부하를 줄여 재발을 방지하도록 수정한 버전입니다.
