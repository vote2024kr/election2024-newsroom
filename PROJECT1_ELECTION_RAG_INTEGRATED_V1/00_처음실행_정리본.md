# NEWSROOM LAB — 정리본 실행 안내

이 정리본은 한글화 및 2024 총선 자료가 적용된 원본 프로젝트를 기반으로 합니다. 별도 패치를 재적용할 필요가 없습니다.

## Windows 실행
1. 전체 압축을 풀고 Python 3.12가 설치되어 있는지 확인합니다.
2. `뉴스룸_실행_한글.bat`를 실행합니다. 첫 실행에서 `.venv`를 새로 만들고 requirements.txt의 라이브러리를 설치합니다(인터넷 필요).
3. 자동으로 열리는 통합운영실 화면에서 실제 확정 결과를 확인합니다.
4. 종료: `뉴스룸_종료_한글.bat`.

기존 `START_PROJECT1_WINDOWS.bat`도 보존했습니다. 구형 설치/패치 안내 및 기존 SHA256 목록은 과거 버전의 기록이며, 현재 정리본의 파일 검증 목록은 `CLEANUP_MANIFEST_SHA256.json`입니다.

## 정리 내용
- PC 고유 경로의 Python 가상환경, 자동 백업 4개, 적용 완료된 패치 설치 폴더, workbench의 이전 버전 ZIP 보관본, Python 캐시 제거
- 동일 SHA256인 선관위 PDF 3개를 현행 `newsroom/real_data/turnout_report_2024.pdf` 한 개로 통합. `/api/real/turnout-report.pdf`와 `/api/v2/report.pdf` 주소는 유지
- 패치의 PDF 근거검색색인을 코드가 찾는 루트 경로로 이동
- 기존 실제 개표 JSON·투표율 JSON·PDF·엑셀 원본·투표율 ZIP, UI, 기능, 테스트 및 과제 문서/증빙, 기존 SQLite 기록 보존
- Windows 가상환경 재설치가 필요하므로 배포 용량과 최초 실행 후 설치 용량은 다릅니다.
