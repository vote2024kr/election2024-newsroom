# V5 3차 개편 검토본 (GitHub 미반영)

## 이번에 추가 수정한 사항

1. 메인 시간별 투표율 꺾은선그래프: 4월 10일 **13:00·53.4%** 지점에 화살표와 `13시 · 사전투표율 포함됨` 문구 표시. 기록이 13시에 도달하기 전에는 표시하지 않음.
2. 지역·선거구 탐색: `← 이전 단계로` / `⌂ 전국 지도 보기` 두 버튼 추가. 단계별 선택값을 유지/초기화해 상위 지도로 복귀.
3. 투표율 분석: **높은 투표율=진한 파란색, 낮은 투표율=연한 파란색**으로 단계별 색상을 정정하고 범례 표시. 실제 지도 지리경계 불러오기 실패 시 투표율을 색상 타일로 구분하여 표시(타일은 실제 행정구역 지도가 아님).
4. 사진·영상 자료: 이전 버전 화면 4개 및 교육용 예시 이미지 3개는 **현재 메뉴에서 제거**. 중앙선관위 실제 자료로 신규 제작한 **데이터 CG 6종**으로 교체. 기존 파일은 다른 기능 호환성을 위해 디스크에서 삭제하지 않음.
5. 독립 HTML 미리보기에도 사진·영상 자료 탭 및 6개 CG 이미지를 직접 삽입. 실제 DB와 연결하지 않고 브라우저로 열람 가능.

## 데이터 표기 주의
- `선거일 투표율 51.8%`는 **표본조사** 결과이며 전국 실제 최종 투표율 67.0%와 모집단/분모가 다름.
- 지역구 후보 개표 결과는 선거관리위원회 최종 결과 사본에서 가져오고, 임의 개표 중간 득표는 생성하지 않음.
- `2024.04.11 10:25`는 당시 보도를 기준으로 재현한 최종 시각이며 중앙선관위가 분 단위로 인증한 정확한 종료 시각이라고 단정하지 않음.
- 이미지 6종은 정확한 수치로 새로 디자인한 **정적 CG**이고 방송사가 제공한 사진이나 실제 브라우저 화면을 캡처한 것이 아님. 동영상 파일은 아직 없음.

## 열람 방법
- **설치 없이:** `V5_3차_브라우저_미리보기.html` 더블클릭. 상단 `사진·영상 자료` 탭도 사용 가능.
- **DB 없이 전체 V5 웹사이트 열기:** 프로젝트 폴더의 `V5_2차_웹사이트_검토실행.cmd` 실행. 브라우저 `http://127.0.0.1:8550/safe2024?page=media`에서 6개 CG 확인.
- **원본 운영 DB 연결:** 이전 `RUN_POSTGRES_NEWSROOM.cmd`는 변경하지 않음. 사용자가 겪은 `psycopg` DLL `파일 이름이나 확장명이 너무 깁니다` 오류는 비밀번호 오류가 아니며, 프로젝트 경로를 `C:\V5\`처럼 짧게 정리한 뒤 가상환경을 다시 만들고 실행하는 방법을 우선 권장. 검토 자체는 DB 연결이 필요 없음.
- 실제 254개 지역구 지리경계 지도는 기존처럼 첫 서버 실행 시 공개 원본 다운로드가 필요할 수 있음. 지도 원본을 가져오지 못하면 대체 캡처/타일이 표시됨.

## 권한 및 보존
- GitHub에는 커밋·푸시하지 않았으며 본 ZIP은 로컬 검토 사본.
- 운영 DB 및 실제 개표 원자료는 변경하지 않음.
- 메뉴에 표시하지 않는 이전 원본 캡처 및 학습 이미지 파일은 해당 코드와 다른 경로가 참조할 가능성을 고려해 ZIP 내부에는 보존.

## 이번 추가 화면 배치 변경 (첨부 승인 시안 기준)
- 기존 전국/선택 지역/시군 목록/후보 결과 4열을 상단의 **전국 지도(확대), 선택 지역 지도, 선거구 최종 결과** 3열로 분리
- **시·도 선택**과 **시·군/지역구 목록·선택·검색**을 하단 2열로 이동
- 기존 후보 득표/실제 지역구 투표율·지도 클릭·선택 강조·검색·이전 단계/전국 지도 보기 기능 및 다른 메뉴 보존
- 전국 지도는 원본 벡터 지도 영역의 가로폭을 확대. 지도 원본을 내려받지 못하면 기존 대체 이미지가 노출됨
- 이 추가 변경은 **지역·선거구 탐색 화면 구성만** 변경하며 선거 데이터·기존 DB·시간대별 투표율 시계열은 바꾸지 않음
