NEWSROOM LAB | PostgreSQL 안정 화면 V4

기존 V3를 덮어쓰지 마세요. V4 ZIP을 별도 새 폴더에 풀어 사용합니다.

1) 실행 중인 이전 NEWSROOM 서버를 종료합니다.
   - 이전 버전 폴더의 "뉴스룸_종료_한글.bat" 사용
2) V4 압축을 새 폴더에 해제합니다.
3) RUN_POSTGRES_NEWSROOM.cmd 실행
4) 데이터베이스 정보의 기본값은 기존대로 유지하며 Enter 입력
   DB: Election2024 / 호스트: localhost / 포트: 5432 / 계정: postgres
5) PostgreSQL 비밀번호 입력(입력 중 화면에 글자가 보이지 않는 것이 정상)
6) 브라우저에 표시되는 http://127.0.0.1:8541/safe2024 를 확인합니다.

위 페이지는 실제 2024년 개표·투표율 자료만 서버에서 HTML로 그립니다.
오래된 브라우저 코드, 반복 감시, WebSocket, 모의 개표 엔진을
첫 화면의 브라우저에서 실행하지 않습니다. 자바스크립트가 필요 없습니다.

주소창에 127.0.0.1:8541 을 직접 입력해도 PostgreSQL 모드에서는
/safe2024 안정 화면으로 자동 이동합니다.

기존 웹페이지·기존 가상 개표 기능도 삭제되지 않았습니다.
- 기존 NEWSROOM: http://127.0.0.1:8541/legacy-newsroom
- 기존 통합운영실: http://127.0.0.1:8541/project1?mode=real
- PostgreSQL 데이터 상태: http://127.0.0.1:8541/api/real/db-status

변경 사항
- 안정적인 2024년 실제 개표·투표율 서버 렌더링 화면 추가
- 지역구 상세, 비례대표, 연령·성별 투표율, 통계, 기사 초안,
  근거 질문, 방송 대본, CSV 다운로드, 학습 자료, 미디어 메뉴
- 기존 프로젝트 및 DB/원자료/기존 JS 기능 유지
- PostgreSQL 모드에 한해 기본 주소를 안정 화면으로 연결

확인된 검증 범위
- 원본 데이터와 동일한 형태를 사용한 로컬 서버 응답 및 브라우저 렌더링
- 개별 화면 11개, 일부 지역/질문 필터, CSV 다운로드 3종
- 기존 자동시험 129개 통과

주의
- 사용자 PC의 실제 PostgreSQL에 접속한 브라우저 실행 시험은 이 환경에서
  할 수 없으므로 완료를 보장하지 않습니다.
- 기존 브라우저 화면의 멈춤 원인을 단일 원인으로 확정하지 못했습니다.
  V4는 위험한 스크립트를 실제 결과 초기 화면에서 배제하는 별도 구현입니다.
- 실제 선거 당일 시각별 개표자료가 아닙니다.
