# Election Data Analytics V0.4 — LOCAL ONLY

**GitHub에 등록하지 않음 · 동영상/신규 CG 제작 안 함 · 기존 V0.3 보존한 새 로컬 폴더**

## 실제로 구현된 기능
- 기존 교육용 모의 개표 및 8개 분석 그래프, RAG 모의 기사·검수, 기존 미디어 자료 기능은 **삭제/변경하지 않고 보존**.
- 신규 메뉴 **공식 결과 CSV 분석**: 사용자 PC 파일 불러오기, 출처 입력, UTF-8/CP949, 헤더·중복·소계 검사, 시도/선거구별 집계 차트/표.
- 통계기법 6종: 시도별 득표 합, 선거구별 득표 합, 선거구 후보별 득표율, 1·2위 격차, 후보자 수, 선거구 표수 분포.
- 분석 결과 CSV 내보내기. 화면의 행은 30개, 내보내기는 해당 화면에 표시된 행만 포함합니다.
- **가상 재생**: 최종 득표수를 난수로 단계 분할. 실제 개표 당시 진행 상황이 아니며 타임스탬프를 만들지 않음.
- **공식 선거 자료 자동 다운로드/당일 실시간 갱신/원본 인증은 아직 지원하지 않음**. 공식 URL은 사용자가 입력한 메타데이터일 뿐.

## Windows 11 + VS Code

```powershell
cd C:\workspace
# 다운로드한 ZIP의 election_data_local_v04 폴더를 이곳에 압축 해제
cd .\election_data_local_v04

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

```

브라우저: `http://127.0.0.1:8502` → 왼쪽 **공식 결과 CSV 분석** 메뉴 → 출처와 CSV 입력 → 조건 변경.

테스트:

```powershell
.\.venv\Scripts\python.exe -m pip install pytest httpx
.\.venv\Scripts\python.exe -m pytest -q
```

1. 아래 중앙선거관리위원회 공공데이터포털 페이지에서 CSV 다운로드.
2. 별도의 원본 폴더에 보관하고, 업로드 파일의 선거 종류와 컬럼을 확인.
3. 웹사이트에서는 `공식 결과 CSV 분석` 메뉴에서 **수동 선택**. `실시간 개표`라는 표현 금지.
4. 원본과 대조하기 전에는 `사용자가 업로드한 미검증 결과`로 표시.

**현재 수입기 기준:** 2024 지역구 결과 메타데이터에 안내된 `시도명, 선거구명, 후보자, 득표수` 필수 열. 비례대표 자료/2026 API의 실제 구조를 별도 어댑터로 확장해야 하며 **현재 직접 실행 호환 검증이 안 됨**.

## 주의
- 공식 개표 결과 파일에 후보 득표수와 선거구 값이 있더라도 실제 투표율·시각별 개표율·의석수·득표율 추이까지 계산되는 것은 아닙니다.
- 현재 프로그램의 **모의 WebSocket 갱신**은 공식 CSV 화면과 독립입니다.
- 2024 선거구 체계와 2026년 지방선거의 시도 구성은 다를 수 있습니다. 지역명을 하드코딩하지 않고 파일에서 읽습니다.
- 대용량 파일(35MiB 초과)은 별도 데이터 파이프라인이 필요합니다.
- 최초 수입 또는 새 파일 업로드 후 화면이 갱신됩니다. 실제 기관으로부터 자동 새 데이터를 당겨오는 기능이 아닙니다.
- 보안: 프로그램은 기본적으로 **로컬 127.0.0.1**로만 실행하고 인증이 없으므로 인터넷 공개 배포하지 않습니다.

## 검증 상태
- 로컬 pytest **38/38 PASS** (공식 파일을 가장한 테스트용 합성 CSV 기반).

- 기존 소스 V0.3과 다른 폴더로 백업해 원본 보존.
