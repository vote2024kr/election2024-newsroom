# NEWSROOM LAB V0.6 · 빈 그래프·기법 데이터 표시 개선

## 수정 이유
V0.5에서는 공식 결과 CSV를 올리기 전 해당 화면이 비었고, 모의 개표 시계열은 시작할 때 1개 스냅샷만 있어 선이 보이지 않았습니다.

## 이번 수정
- **NEWSROOM LAB 기존 7개 메뉴 및 사진 자료·기사·보도자료 기능 보존.** 동영상/CG 신규 제작 없음.
- 공식 결과 분석실에 **17개 시도/68개 모의 선거구 가상 CSV**를 초기 데이터로 표시(실제 개표와 무관).
- 공식 결과 CSV는 공공데이터포털에서 직접 내려받아 동일 화면에서 업로드할 수 있음. 업로드 후 출처 URL, 해시, 인코딩, 제외행 표기.
- 12개 최종 개표 데이터용 통계기법 및 **각 기법 설명**과 그래프/표 제공. 후보 개인 비율은 특정 선거구 선택이 필수.
- 선관위 원천 CSV의 `후보자` 열에 섞인 **선거인수·투표수·무효투표수·기권자수** 등은 후보 득표에서 제외.
- 모의 WebSocket 개표 추이 그래프는 시작할 때 **사전 모의 데이터 7단계(0~6)**를 준비. 매 업데이트 실시간 변경(가상임).
- `tzdata` 설치 포함(Windows의 Asia/Seoul 오류 수정).
- PDF/영상/CG 신규 제작·GitHub 등록 없음.

## 실제 선거 자료 연결
1. https://www.data.go.kr/data/15025527/fileData.do 에서 2024-04-10 **제22대 국회의원선거 지역구** 개표결과 CSV 내려받기.
2. 사이트 `공식 결과 CSV 분석` → CSV 선택 → `CSV 분석하기`.
3. 시도/선거구/기법을 선택하여 계산. 전국 분석은 **지역 합계**, 전국 하나의 후보 순위가 아님.
4. 공식 원본인지 시스템이 자동 검증하지 않으므로 **업로드 출처가 기관 이름이라고 해서 '검증됨'으로 표시하지 않음**.

**중요:** 여기에 실제 공식 CSV 파일 자체는 포함하지 않았습니다. 실행 환경에서 원문 CSV를 직접 내려받지 못했습니다. 초기 차트의 수치는 모두 재현 가능한 교육용 가상 데이터입니다. 개표 진행 이력과 당선 예측도 공식 CSV에는 없으므로 가상과 실측을 절대 합치지 않습니다.

## 실행
`START_NEWSROOM_LAB_V06.bat` 더블클릭(새 버전은 **8510 포트**). 기존 `start_windows.bat`도 새 실행기로 연결됩니다. 또는 PowerShell에서:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

브라우저: 더블클릭 시 http://127.0.0.1:8510 · 수동 `python server.py` 실행 시 http://127.0.0.1:8502
테스트: `.\.venv\Scripts\python.exe -m pytest -q`
