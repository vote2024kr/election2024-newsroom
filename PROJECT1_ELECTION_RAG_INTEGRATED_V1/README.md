첨부 「프로젝트 1·2·3 작업지시서 요약」의 프로젝트 1과 기존 「AIJ P1 RAG 모델 기반의 선거 보도 구성하기 작업지시서」 기준으로 점검했습니다.

## 실행
1. Windows 11, Python 3.12 설치.
2. ZIP을 한 폴더에 **전부 압축 해제** (하위 폴더 구조 유지).
3. `START_PROJECT1_WINDOWS.bat` 더블클릭. 첫 실행은 인터넷을 통해 Python 패키지 설치.
4. 브라우저: **http://127.0.0.1:8541/project1**.
5. 문제가 있으면 VS Code 터미널을 프로젝트 폴더에 열고 아래 명령을 직접 실행:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn project1_app:app --host 127.0.0.1 --port 8541
```

- `/` — **기존 NEWSROOM LAB V0.7 화면/기능 유지**. 전국/시도/선거구, 그래프, CSV 업로드, 원래 기사/RAG/사진 메뉴.

### V1.1 선거 전용 분석 추가
- 통합 운영실 **02 선거 통계** 화면에서 선거 보도에 적합한 10개 기법만 선택할 수 있습니다.
  - 교육용 실시간 모의 개표 4종: 후보 득표율, 선두 격차, 후보 누적 변화, 단계별 추가 집계.
  - 최종 결과 CSV 6종: 선거구 합계, 개별 선거구 후보 득표율, 선두 격차, 근소 격차, 시도 합계, 득표수 분포.
- `/api/project1/election/methods`, `/api/project1/election/analyze`가 기존 계산 함수를 연결하며 **새로운 임의 통계값을 만들어내지 않습니다**.
- 개별 후보 득표율은 반드시 같은 선거구 내부 후보 득표수 합계를 분모로 사용합니다. 전국 후보 합산 및 후보간 다른 선거구 혼합은 차단합니다.
- 최종 결과 CSV에 시간별 스냅샷이 없으면 실시간 추세를 복원하지 않습니다. 선거인 수만으로 실제 **투표율·개표율을 산출하지 않습니다**.
- 기존 뉴스룸 화면·통계 워크벤치 17종·영상/CG 자료·기사/RAG/승인/감사 기능은 삭제하거나 축소하지 않았습니다.
- 선거 분석 기법 상세 및 현재 한계: `docs/PROJECT1_ELECTION_METHODS_V11.md`.
- `FILE_MANIFEST_V11_SHA256.json`은 이번 V1.1 소스 파일의 검증 목록이며, 기존 `FILE_MANIFEST_SHA256.json`은 원본 V1.0 이력 확인용으로 보존했습니다.

- 데스크톱·태블릿·모바일에 맞춘 가독성과 카드 배치 개선. 기존 뉴스룸과 공통 통계툴 UI는 보존했습니다.

### 추천 시연 순서
1. `/project1`에서 모의 개표 단계를 진행 → 대시보드 숫자 갱신 확인.
2. 통합 운영실 `02 선거 통계`에서 선거 전용 기법 선택 → 계산 → 그래프·근거표 확인. 필요하면 `현재 결과 CSV → 분석툴 전달` → 통계툴의 전체 17종 탐색.
3. 근거 검색 → `표수 오류` 기사 초안 생성 → **승인 차단** 확인 → `정상` 기사 생성 → 사람 승인 사유 입력.
4. `/api/project1/audit`에서 SQLite 이벤트 목록 확인.
5. 기존 `/` 화면에서 선거구 탐색·지역별 그래프·CSV 공식 최종 결과 분석·기사 확인.

### 구현 상태
- 뉴스룸 WebSocket은 난수 **모의 개표** (실제 공식 당일 피드 미연결).
- 사용자 제공 공식 최종 결과 CSV는 **출처 URL을 입력해도 앱이 공식 원본과 대조하지 않음**. 실제 개표 과정 재생은 가상.
- 프로젝트1 RAG 검색은 **교육용 근거 문서 TF-IDF 희소 벡터 검색**. LangChain+LLM 기반 생성형 RAG가 아님.
- 기사 초안은 규칙 기반 템플릿. AI 생성 기사 또는 자동 게시 기능 없음.
- 검수는 사람 입력 버튼이지만 **로그인·인증 없는 로컬 실습 승인**. 인터넷 공개용이 아님.
- 기존 뉴스룸의 기사/승인 상태와 업로드 데이터셋은 메모리. 신규 프로젝트1 감사 이벤트만 `data/project1_events.sqlite3`에 저장.
- **영상·CG 신규 제작은 사용자 지시로 보류**, 기존 뉴스룸의 이미지·기획 메뉴 보존.
- **GitHub에 아무것도 올리지 않았음**.
