# 2024년 제22대 국회의원선거 데이터 상황실 — V5 최종 확정본

> **확정 일자:** 2026-11-24 · **기준:** 사용자가 승인한 최신 3차 V5 소스와 화면. **과거 검토본의 안내가 아닌 현재 구현 기준**입니다.

## 프로젝트 요약
중앙선관위 최종 선거 결과와 당시 실제 확인된 투표·개표 관측 기록을 시간 흐름·전국 요약·지역구별 상세 탐색으로 나눠 보여주는 데이터 저널리즘 학습용 웹사이트입니다. 교육용 모의 개표/워크벤치/RAG 기능은 별도 유지하며 **2024년 당시 실시간 개표에 연결하지 않습니다**.

## 2. 실행
- **운영 데이터 모드:** 프로젝트 폴더에서 `RUN_POSTGRES_NEWSROOM.cmd` 실행. `Election2024` PostgreSQL이 필요하며 DB 암호는 저장하지 않습니다. 서버 주소·포트는 기존 실행기를 따릅니다.
- **검토 모드:** 기존 `V5_2차_웹사이트_검토실행.cmd` 또는 `V5_3차_브라우저_미리보기.html` 사용. 이 모드는 최종 운영 DB 검증의 대체가 아닙니다.
- **대표 주소(로컬 실행기 기본 설정에 따라 조정):** `http://127.0.0.1:8541/safe2024`
- **주의:** 운영 실행기는 `historical_replay_2024_v2`에 41개 관측 기록을 재등록할 수 있습니다. 원본 선거 결과 테이블과 구분하세요.
- Windows에서 `ImportError: DLL load failed / 파일 이름이나 확장명이 너무 깁니다`가 발생하면 프로젝트 경로·기존 가상환경과 `psycopg` 로딩 문제를 우선 확인합니다. 암호가 틀렸다고 단정하지 않습니다.

## 3. 자료 기준
- 전국 실제 최종 투표율 **67.0%** / 전체 표본 **67.2%** / 사전투표율 **31.3%** / 선거일 대상 표본 **51.8%**.
- 지역구별 투표율: 해당 선거구 **투표수 ÷ 선거인수 × 100**. 시·도 전체 발표값과 구분.
- 지역구 **254**, 후보 **693**, 비례대표 의석 **46**, 전체 의석 **300**.
- 마지막 완료 시각 **2024-04-11 10:25**는 당시 보도 기준으로 설정한 재현 시각. 공식 인증 종료시각이라고 주장하지 않습니다.
- 254개 선거구 지도 경계와 SQL 지역구 ID를 대조합니다. 원본 지도가 없으면 대체 화면을 사용합니다.
- 중간 지역구 후보 득표를 추정하지 않고 원본·기사·조사방법 출처를 확인합니다.
