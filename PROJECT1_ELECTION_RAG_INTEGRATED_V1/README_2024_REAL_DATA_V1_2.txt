NEWSROOM LAB V1.2 — 제22대 국회의원선거 실제 최종 개표 + 투표율 분석
========================================================================

[실행]
1. 이 ZIP을 전체 압축 해제합니다.
2. Windows에서 START_PROJECT1_WINDOWS.bat 더블클릭 (Python 3.12 필요).
3. 브라우저가 자동으로 http://127.0.0.1:8541/ 를 엽니다.
   자동으로 열리지 않으면 주소를 직접 입력하세요.
4. 화면 왼쪽 '2024 총선 확정 결과'가 기본 선택됩니다.
   '교육용 모의 개표'로 전환하면 기존 가상 개표 기능을 계속 사용 가능합니다.
5. 기존 프로젝트 1 통합 실습 페이지: http://127.0.0.1:8541/project1

[수정된 기능]
01 전국 개표 종합: 지역구(254석) + 비례(46석) 의석별 그래프,
   연계 정당 합산 300석 의석, 비례대표 전국 득표율, 17개 시·도.
02 지역·선거구 탐색: 지역구 254개 후보 득표수·유효표·무효표·승자·격차.
   비례대표는 별도 구·시·군 253개 지역 중 선택하고 정당별 득표율 표시.
03 RAG 기사·검증: 실제 투표율 PDF(190쪽) + 실제 개표 엑셀에 근거한
   검색·질의응답(출처·PDF 쪽수 표시)과 검토 전 기사 초안.
   중요: 현재는 규칙 기반 응답/원문 키워드 검색이며 생성형 LLM/벡터 RAG는 아님.
05 통계·그래프: 연령/성별 표본투표율, 사전투표 전수투표율, 실제 지역별
   투표율, 비례대표 지역별 정당 득표율, 지역구·비례 의석 그래프.
04 기존 모의 방송 CG 및 06 기존 CSV 실습은 보존. 07·08 및 기타 원래 기능도 보존.

[공식 원본과 교차검증이 필요한 부분]
- 사용자 제공 '제22대 국회의원선거 개표결과.xlsx'에서 추출했습니다.
  시트: 지역구, 비례대표. 정당별 유효득표수의 합계와 전국 합계 검증 수행.
- 본 투표율 보고서의 연령·성별 전체 투표율은 1,505개 투표구 표본조사.
  사전투표는 통합선거인명부에 의한 전수조사.
- 비례대표 의석 배분(14/18/12/2석)은 투표수만으로 산출하지 않고
  제22대 총선 별도 의석 배분 결과를 적용함.
  의석 참고: https://m.ohmynews.com/NWS_Web/Event/Elect/2024/counting.aspx
- 지역구 254개와 비례대표 253개는 구분 단위가 다릅니다.
- 최종 개표 집계에 투표소별 실시간 시각 데이터가 없으므로 실제 2024년 개표
  시간대별 변화를 재현하지 않습니다. '개표 완료 100%'는 최종 확정 상태입니다.
- 이용자 제공 파일을 전국 공식 배포 원본과 독립 다운로드하여 대조한
  것은 아닙니다. 외부 송고 전 선관위 공개 원본 확인과 사람 검수 필요.
- 생성형 LLM 질문응답·보도 송고·실제 편집장 인증·실시간 API는 이번 범위 아님.
