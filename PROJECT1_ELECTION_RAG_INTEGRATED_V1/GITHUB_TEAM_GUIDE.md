# NEWSROOM LAB 팀 공동작업 안내

- 프로젝트: 2024년 제22대 국회의원선거 데이터 저널리즘 대시보드
- PostgreSQL 데이터베이스: `Election2024`, 스키마: `election_lab`
- 결과: 2024년 최종 개표자료와 선관위 투표율 분석자료이며 실시간 개표정보가 아닙니다
- 기본 안정화 화면: `http://127.0.0.1:8541/safe2024`
- 로컬 실행: `RUN_POSTGRES_NEWSROOM.cmd` (Python 3.12 및 PostgreSQL 필요)
- PostgreSQL 비밀번호와 개인 환경설정, `.env`, 가상환경, 임시 로그를 GitHub에 올리지 않습니다
- 팀원은 작업 전에 `git pull --ff-only`로 최신 버전을 받고, 수정 후 테스트하고 커밋합니다
- 충돌을 줄이기 위해 작업별 브랜치와 Pull Request 사용을 권장합니다
- 현재 알려진 후속 작업: 최초 데이터 로딩 속도 개선

**참고:** 이 안내 파일은 업로드 권한 검증을 위한 첫 파일입니다. 전체 V4 프로젝트 파일의 업로드가 완료됐는지는 저장소 파일 목록으로 별도 확인해야 합니다.
