이 프로젝트는 확보된 기존 V5 **전체 소스 사본**에 사용자가 확정한 UI 개선과
2024년 선거의 검증된 41개 시간별 관측 기록을 추가한 **로컬 검토용 빌드**입니다.

주장하지 않습니다. 기존 GitHub 저장소에 커밋·푸시하지 않았습니다.

## 2. 기타 메뉴 개편

- **전국 확정 개표:** 지역구 당선 지도와 지역구·비례대표 도넛, 전체 의석 반원 그래프
- **투표율 분석:** 17개 시·도 실제 최종 투표율을 지도 색상 + 지역별 순위로 표현.
  선택 지역을 강조하고 다른 지역을 흐리게 처리.
  성별×시·도 표본조사 교차분석과 연령별 비교 유지.
  메인 지표에서는 전국 표본 투표율 67.2% 카드를 제외하되 조사방법 설명은 보존
- **지역·선거구 탐색:** 전국→시·도→지역구 지도 연결과 기존 후보 목록·투표수 표 보존
- **개표 분석:** 의석 구성 도넛·300석 반원과 접전 지역구 12곳 후보별 득표 막대 추가
- **비례대표 개표:** 비례대표 46석 도넛 추가. 정당별 실제 득표표 원본 유지
- **사진·영상 자료:** 기존 2024 분석 화면 캡처 4건과 교육용 예시 사진을 구분해 표시
- **기타 메뉴/API:** 기사 초안, RAG 검색, 방송 CG, CSV, 보도자료, 원본 프로젝트는 삭제하지 않음

## 3. Windows에서 검토용 UI 확인

1. ZIP을 **새 폴더**에 해제합니다. 기존 GitHub 폴더에 덮어쓰지 않아도 됩니다.
2. 기존 V5의 `.venv`가 있으면 프로젝트 루트에 복사하거나 같은 환경에서 실행합니다.
   Python 환경이 없으면 가상환경을 만든 다음 `requirements.txt`를 설치합니다.
3. 프로젝트 폴더의 `REVIEW_NO_DB.cmd`를 실행합니다.
4. 브라우저 `http://127.0.0.1:8550/safe2024`에서 확인합니다.
5. 왼쪽 시간대별 재생 → 바로가기 슬라이더를 41번째로 이동하면 최종 공개를 검토할 수 있습니다.

`REVIEW_NO_DB.cmd`는 **기존 JSON 사본을 읽기만 하는 검토용 실행기**입니다.
PostgreSQL 연결 정보도 요청하지 않고 DB를 변경하지 않습니다.
상단에 검토용 경고 배지가 표시됩니다.

실제 DB 버전은 기존의 `RUN_POSTGRES_NEWSROOM.cmd`로 실행해야 합니다.
이때만 기존 `Election2024` PostgreSQL을 사용하며 시간 기록용
`election_lab.historical_replay_2024_v2`에 41개 시점을 재등록합니다.
**기존 지역구 득표 테이블과 v1 기록 테이블은 수정하지 않습니다.**

## 4. 254개 지역구 실제 지도에 관한 예외

이 검토본은 이전에 전달된 전체 ZIP을 기반으로 작성했으나 당시 ZIP에는
`newsroom/static/map_22nd_2024.geojson` 원본 경계가 없었습니다.
정확한 선거구 경계가 없는 상태에서 **가짜 지도를 생성하지 않도록** 했습니다.

- 처음 지도를 열면 공개 GitHub에 이미 등록된 오마이뉴스 MIT 기반 **254개 지역구 GeoJSON**을
  HTTPS로 받아 ID 254개를 검증한 뒤 프로젝트 정적 폴더에 저장합니다.
- 최초 지도를 여는 PC에 **인터넷 연결이 필요**합니다. 이후에는 로컬 지리자료를 재사용합니다.
- 네트워크가 차단되면 기존 V5 지도 **캡처(클릭 불가)** 및 17개 시·도 안내로 대체합니다.
  개표 진행 단계에서는 당선 정당 색을 노출하지 않는 실제 지도 실루엣 캡처를 사용합니다.
- 원본 출처: https://github.com/OhmyNews/2024_22_elec_map
- 지리자료 라이선스: `docs/OhmyNews_MAP_MIT_LICENSE.txt`
- **실제 선거구 지도 254개 경계의 실브라우저 드릴다운은 이 검토 환경에서 원본 다운로드 제약으로 최종 검증하지 못했습니다.**

원하시면 기존에 내려받은 최신 GitHub ZIP에 들어 있는
`newsroom/static/map_22nd_2024.geojson`을 같은 경로에 복사해
인터넷 없이 254개 지역구 지도를 사용할 수도 있습니다.
