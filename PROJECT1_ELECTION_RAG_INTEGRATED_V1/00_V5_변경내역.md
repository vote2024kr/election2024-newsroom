# V5 — 제22대 총선 과거 투·개표 기록 자동 재생

## 개선
- 첫 접속 `/safe2024`는 PostgreSQL 전체 개표자료를 읽기 전에 검증된 과거 시간대별 기록을 바로 표시합니다.
- 전국 투표율: 2024-04-10 07~18시 12개 시점, 중앙선관위 제공 수치.
- 전국 **지역구** 개표율: 당시 기사에서 확인된 7개 시점 + 최종 확정 100%, 중간 시간은 일부만 확인됨.
- 5/10/15초 간격, 일시정지·재시작·다음 단계 지원.
- 13시부터 사전투표 등을 합산하므로 낮 12시와 13시의 비율 비교에 주의.
- **실시간 네트워크 개표 아님**. 당시 기록 시뮬레이션으로 재생하는 교육용 기능.
- 실제 254개 선거구별 시간대 득표자료는 없으므로 역산해 가짜 실측값을 만들지 않았습니다.
- 최종 확정 개표와 기존 보조 기능은 `/safe2024?page=final` 및 기존 메뉴에 그대로 보존.
- V4 안정형 HTML 기반을 유지하며 원래 과부하를 일으키던 무거운 SPA/WebSocket을 켜지 않습니다.
- 최종 DB 자료 조회는 첫 조회 후 서버 메모리 캐시를 이용합니다. 실제 DB의 변경을 반영하려면 서버를 재시작해야 합니다.

## 출처
전국 투표율 표: https://www.ohmynews.com/NWS_Web/Event/Elect/2024/counting.aspx
개표율 기록 출처는 `data/election_2024_replay_observed.json` 항목별 `source` 필드 참조.

## 실행
기존과 같이 `RUN_POSTGRES_NEWSROOM.cmd` 실행 → 비밀번호 입력 → 첫 페이지 `/safe2024`.

## GitHub
비밀번호, `.venv`, `.env` 및 개인 캐시는 업로드 금지. `NEWSROOM_LAB_V5_GitHub_업로드.cmd`는 별도 배포 도구에 포함됩니다.

## PostgreSQL에 새로 추가되는 데이터
- V5 실행기가 `election_lab.historical_replay_2024` 테이블을 **새로 생성**합니다.
- 표본: 12개 투표율 시점 + 7개 전국 지역구 개표율 보도 시점 + 최종 완료 1건 = 20행.
- 이미 등록된 데이터는 `ON CONFLICT DO NOTHING` 처리하고 자료가 불일치하면 작업을 중단합니다.
- 기존 개표 최종 결과·투표율 106개 항목 및 `public` 스키마는 수정하지 않습니다.
- 매 갱신 시 화면은 `/safe2024/api/replay/{index}`에서 PostgreSQL의 해당 시점 한 행을 조회합니다.
- 브라우저에서 데이터베이스 연결 오류가 발생하면 재생을 중단하고 오류를 표시하며 임의 값으로 넘어가지 않습니다.
