NEWSROOM LAB V5 — 2024 총선 기록 자동 재생

(1) Windows 실행: PROJECT1_ELECTION_RAG_INTEGRATED_V1/RUN_POSTGRES_NEWSROOM.cmd
    기존 Election2024 PostgreSQL 비밀번호를 입력합니다.
    새 과거 시간별 기록 20개가 election_lab.historical_replay_2024에 보존됩니다.
    첫 화면은 과거 기록 재생입니다. 최종 개표는 별도 메뉴로 이동합니다.
(2) 최초 GitHub 업로드(한 번만): PUSH_TO_GITHUB.cmd
    Git for Windows를 설치하고 이 파일을 실행하면 공동 저장소를 복제하여 V5 소스를 추가합니다.
    이미 팀원 코드가 올라가 있는 경우 원본을 덮어쓰지 않고 중단하도록 설계했습니다.
(3) GitHub: https://github.com/vote2024kr/election2024-newsroom

참고: 과거 자료를 갱신해 보여주는 교육용 프로그램입니다. 당시 실제 시간대별 자료가 아닌 새로운 득표수나 후보별 중간 개표자료는 생성하지 않습니다.
